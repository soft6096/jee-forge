# 中间产物导出 HTML（/export-html，阅读/存档旁路）

**定位**：把「给人读 / 存档」的中间产物导出成美观、少文件、带导航的 HTML；**这是一条按需的旁路，不改动任何 md，也不进主流程**。阅读体验与存档用 html，机器读写与真源永远是 md。

> [!IMPORTANT] 真源是 md，html 只是导出视图
> - AI 读写、续跑、核对、覆盖报告引用的**一律是 md**；html 给人看、给存档、发给协作方。
> - **绝不把 html 当产物回写成 md**，**绝不让 AI 回读 html 代替 md**（html 标签灌回上下文反而更烧 token）。
> - 导出是**可选、按需**动作：只在用户说"导出 html / 给我网页版 / 存档"时执行；每个产物步骤落盘 md 后**不自动导出**。

## 何时用 / 何时不用

| 场景 | 处理 |
|---|---|
| 用户要"把某模块产物导成 html / 网页版 / 方便存档 / 给非技术方看" | 执行本命令 |
| 3.x.2 接口清单 | **保持 md，不导出**（要交给前端 AI 生成/调试代码，md 更合适） |
| 1.3 澄清清单 / 0.6 可行性卡片（核心用法是人**逐条勾选**） | 谨慎：静态 html **无法回填勾选**，勾选请改 md；html 只作只读预览 |
| 2.1 约束 / 5.1 编码指令 / 4.1 任务拆解 / 通用-* （AI 输入或机器读写） | **不导出**（导出对 AI 无用、反而增文件） |

## 执行

1. **定位脚本**（纯标准库，无外部依赖；路径相对**本 skill 目录**，用绝对路径执行）：
   ```bash
   python3 <本 skill base dir>/scripts/export_html.py <输入> --products --index
   ```
   - 无 Python 环境：告知用户本命令需要 Python 3.8+（仅标准库），或改由用户自行渲染；**不降级手写 html**。

2. **确定输入**（按用户所指）：
   - "导出 XX 模块" → 输入 = `docs/<模块名>V<版本>-<时间戳>/`，加 `--products`（只导约定阅读型产物，自动排除 3.x.2 接口清单）+ `--index`（生成模块级 `index.html` 导航）。
   - "只导这份技术方案 / 只导核对报告" → 直接传对应 md 文件路径（可多个）。

3. **运行并如实报告**：脚本逐条打印 `源 → 输出.html`，末尾说明"md 仍为真源、未改动任何 md"。把导出目录与 `index.html` 路径回报给用户。

## 导出范围与命名

- 输出 `<同名>.html`，默认与源 md **同目录**（`-o <dir>` 可改）；`--index` 额外生成 `index.html`。
- 约定阅读型产物（`--products`）：`0.5-*存量*扫描*`、`0.9-*需求*`、`1.1-*功能清单*`、`3.*.1-*`、`5.2.*-*`、`5.3.*-*`；**排除** `3.*.2-*`（接口清单）。

## 已知限制（如实告知用户，够用即可）

- **复选框是静态的**：`- [ ]` / `- [x]` 渲染成 ☐ / ☑，**点了不会保存**；要改勾选状态请回 md。
- **mermaid 图**导出为纯文本代码块（不联网执行 mermaid.js，保证离线/存档可用）。
- 单文件自包含（内嵌 CSS），可直接发人、可浏览器打印成 PDF。
