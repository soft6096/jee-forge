# 接口契约测试

从技术方案的"验收场景"表翻译成测试代码（**初始为红**，作为 AI 编码的标尺）。

> 契约测试代码规范见 **test-standards** skill（`standards/contract-test-standards.md`），本命令为流程入口。

## 输入

- 第③步的技术方案 md（验收场景表）

## 执行

1. 按模板 `templates/4.2-接口契约测试.md` 翻译测试，每个验收场景一个用例：

- **Controller**：MockMvc 测试（合法入参→期望出参；非法入参→错误码）
- **Listener**：消费逻辑测试（幂等/重复/非法消息/失败进死信）
- **Job**：执行逻辑测试（筛选/防重入/部分失败）

2. 断言必须具体：断字段值、错误码，禁止只断"返回 200"

## 关键规则（防"骗绿"）

- 测试由**人写**（或 AI 生成、人审核），**不交给实现代码的同一个 Agent**
- 写完后**先跑一遍确认是红的**，再进入编码阶段

## 输出

`src/test/java/.../Test<功能名>.java`（按项目测试目录结构）

## 完成标准

- [ ] 技术方案每个验收场景有对应测试用例
- [ ] 每个接口：合法入参 + 非法入参（三态：合法/非法/边界）
- [ ] 断言具体，无"只断 200"的弱断言
- [ ] 测试已运行，确认是红的
