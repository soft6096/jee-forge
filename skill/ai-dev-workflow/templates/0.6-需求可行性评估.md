# 需求可行性评估 - <需求/功能主题>

> 使用说明：这是**可选前置闸门**（**0.6**）的产物模板，命令 `/feasibility`。**仅当需求命中"风险信号"时触发**（见命令判定），普通需求直接跳过进 1.1，零负担。
> 目的：在拆功能、写方案之前回答三个问题——**这需求值不值得做？做不做得动？有没有更稳的路？**（对应 1.1 需求分档管"描述质量"，1.3 澄清管"细节歧义"，本环节管"可行性/方向"，不重复）
> 形式：**一页速评**。AI 读码 + 查文档（含必要的外部调研）后 1 轮内产出草稿，**人拍板结论**。结论：🟢 go（进 1.1）/ 🟡 需澄清（问题清单交人裁决后 go 或 kill）/ 🔴 kill（不做，理由存档）。
> 产物落盘：`docs/0.6-需求可行性评估.md`（一份/批；同一批再次评估 → `docs/0.6-需求可行性评估-<YYYYMMDDHHMMSS>.md`）。
>
