## 硬性检查清单（逐项核对，缺一项即不合格）

| # | 检查项 | 合格判定 | 核对结果 |
| :---: | :--- | :--- | :---: |
| 1 | 配置文件四件套 | `application.yml` + `-dev` + `-qa` + `-online` 四份齐全；profile 激活 `${SPRING_PROFILES_ACTIVE:dev}` 不写死 | ☐ |
| 2 | HikariCP 连接池 | datasource 下 `hikari` 池参数显式配置（maximum-pool-size/minimum-idle/pool-name 等），非仅 url/username/password 三件套 | ☐ |
| 3 | JDBC 字符集 | URL **未写** `characterEncoding=utf8mb4`；推荐不写字符集参数或写 `characterEncoding=UTF-8` | ☐ |
| 4 | JDBC 时区与端口 | `serverTimezone=Asia/Shanghai` 已带；端口与目标环境实际一致（非默认 3306 想当然） | ☐ |
| 5 | MyBatis-Plus 插件 | 分页 + 乐观锁拦截器已注册（参考 java-code-standards `04-templates/ConfigTemplate.java`） | ☐ |
| 6 | MetaObjectHandler | 项目存在 `MyMetaObjectHandler`（@Component）自动填充 createTime/updateTime（参考 java-code-standards `04-templates/MyMetaObjectHandler.java`）；实体 `@TableField(fill=...)` 与之配套 | ☐ |
| 7 | 库表 schema 一致性 | 建库建表显式 utf8mb4；库按当前 schema.sql 全量重建，无旧库旧表遗留；Entity 与 DDL 一一对应 | ☐ |
| 8 | MySQL 驱动版本 | Connector/J 8.x（Spring Boot BOM 管理），无 5.1 旧驱动 | ☐ |
| 9 | 日志配置 | `resources/logback-spring.xml` 已提供（控制台 + 滚动文件 + 环境级 level，参考 java-code-standards `04-templates/logback-spring.xml`）；application.yml 有 logging.level 覆盖 | ☐ |
| 10 | 接口文档依赖 | 接口模块已引 springdoc-openapi（/knife4j）且版本由 BOM 管理；`springdoc.api-docs.enabled` 按环境配置（online 关闭） | ☐ |

## 启动验证（核对完成后）

- [ ] `mvn spring-boot:run` 启动成功，无连接被拒 / 字符集报错 / Unknown column 报错
- [ ] 调用一次含插入的接口（如登录写日志/注册），确认 create_time 自动填充，无 NOT NULL 报错
- [ ] 各环境 profile（dev/qa/online）均能显式切换启动
- [ ] 启动日志落盘到 logs/（滚动文件 Appender 生效），Swagger/knife4j 页面 dev 可访问、online 关闭
