## 老项目约定基线（2.1 存量适配模式的约束来源）

### 1. 包结构与分层

| # | 约定 | 证据 |
| :---: | :--- | :--- |
| 1 | 业务代码放 `com.permission.<模块>` 包，分层 controller / service / mapper / entity / dto / vo | src/main/java/com/permission/ |

| # | 约定 | 证据 |

### 3. 命名风格

| # | 约定 | 证据 |
| :---: | :--- | :--- |
| 1 | Java 类名大驼峰、变量/方法小驼峰；变量 2-3 词有实义（如 `existingUser`、`pageResult`），禁止单字母/无实义缩写 | 抽样 AuthServiceImpl / RoleServiceImpl |
| 2 | 数据库表 `sys_` 前缀（业务表除外）、字段下划线、逻辑删除字段名以老项目实际为准（RuoYi 系 `del_flag` / 通用规范 `deleted`） | sys_user 表 DDL |
| 3 | 时间字段 DATETIME、金额 DECIMAL(10,2) | sys_order 表 DDL |
