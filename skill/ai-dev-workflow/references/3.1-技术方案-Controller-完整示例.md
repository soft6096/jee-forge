#### #2 GET /system/user/{id} — 查询用户详情

**入参示例（请求体 JSON）**：

```json
// 无请求体，路径参数 id=10001
```

**出参示例（成功 / 失败）**：

```json
// 成功
{
  "code": 200, // 【状态码】200=成功
  "message": "操作成功", // 【提示信息】String
  "data": { // 【业务数据】Object，用户详情
    "userId": 10001, // 用户ID（Long）
    "username": "zhangsan", // 用户名（String）
    "email": "zhangsan@example.com", // 邮箱（String）
    "status": "0", // 状态（字典 <类型码>）：0-正常 / 1-停用
    "statusName": "正常" // 状态中文名（String，后端转义，前端直接展示）
  },
  "timestamp": "2026-09-29 20:06:00", // 【时间戳】String
  "traceId": "d4e5f6a7b8c9" // 【链路ID】String
}
// 失败（用户不存在，统一 500）
{
  "code": 500, // 500=<后端异常枚举名，如 USER_NOT_EXIST>
  "message": "用户不存在", // 【提示信息】String，后端异常枚举原文
  "timestamp": "2026-09-29 20:06:00", // 【时间戳】String
  "traceId": "d4e5f6a7b8c9" // 【链路ID】String
}
```

#### #3 GET /system/user/list — 分页查询用户

**入参示例（请求体 JSON）**：


**出参示例（成功 / 失败）**：

```json

  "message": "操作成功", // 【提示信息】String

  "timestamp": "2026-09-29 20:07:00", // 【时间戳】String
```

#### #5 DELETE /system/user/{ids} — 删除用户

**入参示例（请求体 JSON）**：

```json
// 路径参数：ids=10001,10002（逗号分隔批量删除，无请求体）
```

**出参示例（成功 / 失败）**：

```json
// 成功
{
  "code": 200, // 【状态码】200=成功
  "message": "操作成功", // 【提示信息】String
  "data": null, // 【业务数据】批量删除无返回数据；NON_NULL 策略下该字段**整体不返回**（示例保留仅为位置示意）
  "timestamp": "2026-09-29 20:09:00", // 【时间戳】String
  "traceId": "a7b8c9d0e1f2" // 【链路ID】String
}
// 失败（部分 id 不存在，统一 500）
{
  "code": 500, // 500=<后端异常枚举名，如 USER_NOT_EXIST>
  "message": "用户 10002 不存在", // 【提示信息】String，后端异常枚举原文（含定位信息）
  "timestamp": "2026-09-29 20:09:00", // 【时间戳】String
  "traceId": "a7b8c9d0e1f2" // 【链路ID】String
}
```

> [!NOTE] 返回体
> 返回体字段按项目实际（本示例：`Result<T>` = `code` / `message` / `data`，另有 `timestamp` / `traceId`；分页对象用 `Page<T>`，其它框架如 `PageResult` 自行替换）；**禁止 `R` / `Map` 裸返回**（见 java-code-standards 命名规范）。
>
> **失败语义（本模板默认口径，最终以 `2.1-项目约束.md` 的项目实际为准并在本节写明）**：**HTTP 状态码一律 200**——业务异常、权限异常、参数校验异常同样返回 200（全局异常处理器统一 `@ResponseStatus(OK)`），成败**只看 `code`**：业务异常统一 **500**、权限类 **403**、鉴权 **401**，**不使用 400**。前端**不得按 HTTP 状态码分支**，按 `message` 文案分支；参数校验多字段同错时按项目规则拼接（如英文句点 `.`）。
>
> `data` 为 null 时**该字段整体不返回**（NON_NULL 序列化策略）——前端取数前先判字段存在，勿依赖 `data: null`。
