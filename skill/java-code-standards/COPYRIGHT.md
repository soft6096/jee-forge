向本项目提交代码或内容时：

1. **只写原创**：用自己的话重写规则，自己写代码示例
2. **API 可用**：引用公开 API 是安全的，复制实现代码需要授权
3. **标注来源**：若参考了某开源实现后重写，在代码注释注明「参考自 xxx 项目（许可）」
4. **保留声明**：复制 Apache 2.0 代码必须保留版权声明 + NOTICE 文件，并记录来源
5. **GPL 拒绝**：默认禁止引入 GPL/LGPL 代码，除非明确评估并记录
