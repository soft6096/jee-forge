# 验收用例设计规范

生成验收用例（`<功能项>.cases.yaml`）时必须遵循。目标：**验证需求是否实现**，不是覆盖所有字段组合。

## 1. 用例来源：验收场景三态

用例**只从技术方案的"验收场景"推导**，不自行发明：

| 场景态 | 对应用例 | 断言重点 |
|---|---|---|
| 合法 | 正常路径 | 成功结果：status + 关键业务字段（订单号 / 状态变化） |
| 非法 | 参数 / 权限 / 状态非法 | 拒绝：错误 status + 错误码 |
| 边界 | 临界值 / 重复 / 并发 | 边界行为（库存=0、重复提交幂等） |

- 每个验收场景 **至少一条**用例，一一对应可追溯
- 断言必须具体：断字段值、错误码，**禁止只断"返回 200"**

## 2. 核心业务场景优先，**不做字段穷举**

- ❌ **禁止**对字段取值做笛卡尔积穷举（N 字段 × M 取值 = 组合爆炸，用例爆炸且大多数无意义）
- ✅ **等价类划分**：每个字段取一个代表性合法值 + 一个代表性非法值
- ✅ **边界值**：只测临界点（如 0 / 上限 / 上限+1），不测区间内每一点
- ✅ **核心业务场景优先**：覆盖主干流程 + 高风险分支（金额、库存、状态流转、权限）

> 判断标准：**这条用例是否验证了一个独立的业务需求点？** 是 → 保留；只是字段取值不同 → 删。

## 3. 用例文件结构（YAML）

```yaml
# 验收用例：<功能项名>
# 来源：3.<n>.1-<功能名>-技术方案.md 验收场景 / 3.<n>.2-接口清单
module: <模块名>
baseUrl: ${BASE_URL}          # 从环境变量注入，不写死
auth:
  type: bearer                # none | bearer | header
  tokenEnv: ${TOKEN}          # token 从环境变量注入
cases:
  - id: TC-001
    name: 创建订单（合法）
    scenario: 合法            # 合法 | 非法 | 边界（对应验收场景三态）
    request:
      method: POST
      path: /order
      headers: { Content-Type: application/json }
      body: { userId: 88, itemIdList: [1, 2], amount: "299.00" }
    preconditions: []         # 可选：需先造的数据/状态
    expect:
      status: 200
      fields:                 # 关键字段断言（不是全部响应体）
        code: 200
        "data.orderId": isNumber
    assertType: fields        # fields | db | concurrency
  - id: TC-002
    name: 商品不存在（非法）
    scenario: 非法
    request:
      method: POST
      path: /order
      body: { userId: 88, itemIdList: [99999], amount: "100.00" }
    expect:
      status: 400
      fields: { code: 400 }
```

- `baseUrl` / token **一律走环境变量**，禁止写死
- 敏感数据（账号、密码）不进用例文件

## 4. 事务 / 并发类用例（如验收场景含）

| 类型 | 设计 | assertType |
|---|---|---|
| 事务 | WHEN 写操作失败 THEN 查库确认**无残留** | `db`（需 DB 断言） |
| 并发 | WHEN N 并发请求 THEN 断言**不变式**（库存≥0 / 只成功一次）| `concurrency`（**不写精确计数**，避免 flaky）|
| 幂等 | WHEN 同请求发 2 次 THEN 只落库 1 条 | `db` |

## 5. 数据隔离与可复现

- 用例自带前置数据说明（`preconditions`），或依赖固定种子数据
- 写接口（POST/PUT/DELETE）须说明**清理方式**或运行在专用环境
- 用例之间**不依赖执行顺序**（可独立运行、可乱序）

## 自检清单

- [ ] 用例覆盖验收场景三态（合法 / 非法 / 边界）
- [ ] 核心业务场景齐全，且**未做字段穷举**
- [ ] 断言具体（字段值 / 错误码），无"只断 200"
- [ ] baseUrl / token 走环境变量，无硬编码 / 敏感数据
- [ ] 事务 / 并发类用例按不变式断言（非精确计数）
- [ ] 每条用例可独立运行，无顺序依赖
